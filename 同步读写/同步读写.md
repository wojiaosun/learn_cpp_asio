# 服务端
session负责处理回话消息，回传信息
server负责监听，然后循环分配socket
容易踩坑的地方：

> 我们主线程负责监听，分配子线程去建立连接处理任务，但是线程分配完就好了吗？ 看下面的两段server代码，会对服务有什么影响？

![图一](https://i-blog.csdnimg.cn/direct/4a5e1d2a917648de807f1a87bf6b35fb.png)![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/25c2766828994fc7952c386a41741fd9.png)
区别在于少了thread_set.insert(t);这一行，第一段代码的风险在于for结束后，我们auto t这个临时遍历就会析构掉，此时非常有可能子线程还没结束任务，线程就已经析构了，所以这里将线程资源放入set中是保证不被析构。

再有就是主线程必须等子线程全部结束才能结束，也就是下面这一段

```cpp
for (auto t:thread_set)
	{
		t->join();
	}
```

**服务端代码**
```cpp
#include <memory>
using boost::asio::ip::tcp;
const int max_length = 1024;
typedef std::shared_ptr<tcp::socket> socket_ptr;
std::set<std::shared_ptr<std::thread>> thread_set;
using namespace std;

void session(socket_ptr sock)
{
	try
	{
		for (;;)
		{
			char data[max_length];
			memset(data, '\0', max_length);
			boost::system::error_code error;
			size_t length = sock->read_some(boost::asio::buffer(data, max_length), error);
			if (error == boost::asio::error::eof)
			{
				cout << "connection closed by peer" << endl;
				break;
			}
			else if (error)
			{
				throw boost::system::system_error(error);
			}
			cout << "Receive from " << sock->remote_endpoint().address().to_string() << endl;
			cout << "Receive message is (" << data << ")" << endl;
			//回传信息
			boost::asio::write(*sock, boost::asio::buffer(data, length));
		}
	}
	catch (const std::exception& e)
	{
		std::cerr << "Exception in thread :" << e.what() << "\n";
	}
}

void server(boost::asio::io_context& io_context, unsigned short port)
{
	cout << "---welcom bz---"<<endl;
	tcp::acceptor a(io_context,tcp::endpoint(tcp::v4(),port));
	for (;;)
	{
		socket_ptr sock(new tcp::socket(io_context));
		a.accept(*sock);
		auto t = std::make_shared<std::thread>(session, sock);
		thread_set.insert(t);
	}
}

int main()
{
	try
	{
		boost::asio::io_context ioc;
		server(ioc, 10086);
		for (auto t:thread_set)
		{
			t->join();
		}
	}
	catch (const std::exception& e)
	{
		std::cerr << "Exception :" << e.what() << "\n";
	}
	return 0;
}
```
## 客户端
这里就是构建上下文，创建通信端点
```cpp
#include <boost/asio.hpp>
#include <iostream>
using namespace std;
using namespace boost::asio::ip;
const int MAX_LENGTH = 1024;
int main()
{
	try
	{
		//创建io上下文
		boost::asio::io_context ioc;
		//构建endpoint
		tcp::endpoint remote_ep(address::from_string("127.0.0.1"), 10086);
		tcp::socket sock(ioc);
		boost::system::error_code error = boost::asio::error::host_not_found;
		sock.connect(remote_ep, error);
		if (error)
		{
			cout << "Connect failed,code is " << error.value() <<" error message is " << error.message();
			return 0;
		}

		std::cout << "Enter message: ";
		char request[MAX_LENGTH];
		std::cin.getline(request, MAX_LENGTH);
		size_t request_length = strlen(request);
		boost::asio::write(sock, boost::asio::buffer(request, request_length));

		char reply[MAX_LENGTH];
		size_t reply_length = boost::asio::read(sock, boost::asio::buffer(reply, request_length));
		std::cout << "reply is: ";
		std::cout.write(reply, reply_length);
		std::cout << "\n";

	}
	catch (const std::exception& e)
	{
		std::cerr << "Exception: " << e.what() << endl;
	}
	return 0;
}
```
